The inline SVG viewport excludes transparent padding (x=191, y=190, width=368, height=322) and preserves the original outline. The symbol appears before the numeral, proportional to the text, at least 12px high, with an accessible AED label. The visible ISO code is replaced rather than duplicated. The symbol remains black on light backgrounds and white on dark price overlays. Backend values and structured currency identifiers remain ISO codes.
